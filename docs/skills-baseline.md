# Skill baseline and readiness checklist

## Current assessment

The project is beginning in a controlled, knowledge-building phase. The initial focus is to reduce unknowns before any live AWS integration.

## Required skill domains

- AWS foundations: account, region, IAM, ARN, tags, quotas, and CLI usage
- networking: VPC boundaries, security groups, network ACLs, DNS, and TLS
- IAM: roles, trust policies, resource policies, explicit deny, and least privilege
- storage and crypto: S3 policies, KMS, encryption, and secret boundaries
- monitoring: CloudTrail, Config, CloudWatch, and telemetry gaps
- detection: GuardDuty, Security Hub, EventBridge, and normalization limits
- automation: Python, boto3, Lambda, Step Functions, and idempotency
- IaC: Terraform planning, state, drift, and module design
- DevSecOps: GitHub Actions, OIDC federation, and CI security checks
- testing: unit, contract, integration, and security validation

## Phase 0 readiness status

- repository scaffold: complete
- architecture and governance docs: complete
- cost guardrails: documented
- AWS deployment: deferred
- live environment work: blocked pending explicit user approval

## Next learning gate

Before moving beyond Phase 0, confirm the user is comfortable with the project constraints and is ready to continue with the local validation work described by the specification.
