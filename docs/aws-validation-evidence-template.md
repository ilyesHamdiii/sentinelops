# AWS validation evidence template

## Purpose

Use this template to record any future AWS sandbox validation after explicit authorization.

## Header

- Date/time
- AWS account ID
- Region
- GitHub repository and environment
- Operator identity
- Cost ceiling

## Step-by-step evidence

### Discovery

- Asset inventory
- Evidence collected
- Time stamps
- Session ID
- Assessment identity used

### Findings

- Finding ID
- Resource identifier
- Scenario ID
- Severity
- Risk score
- Evidence references

### Approval

- Approval hash
- Action
- Approved by
- Timestamp
- Target resource

### Remediation

- Remediation identity used
- Action executed
- Before state
- After state
- Execution status

### Verification

- Fresh session ID
- Fresh evidence timestamp
- Resolution status
- Verification result

### Cleanup

- Resource names removed
- Cleanup identity used
- Final remaining inventory

## Final note

This document is only filled out for authorized live AWS validation. It is not an execution record for the current workspace.
